# computer_visio_PoC

Requisiti del sistema:
    - il sistema deve riconoscere le facce degli utenti 
    - il sistema deve andare a blurrare le facce degli utenti 
    - il sistema deve adare a identificare una persona 
    - il sistema deve contare il numero di persone all'inerno del negozio
    - il sistema deve memorizzare il numero di persone che sono entrate ed andare a resettare il counter
    - il sistema deve sommare il numero di persone entrate nel negozio in tutta la giornata 
    - il sistema mostra un report con i dati memorizzati 
    - il sistema passa i dati dalla memoria persistente alla memoria non persistenete quando viene premuto il tasto salva 
    - il sistema permette attraverso un'interfaccia grafica di disegnare le zone morte
    - il sistema non va a considerare la zone morte nel momento del conteggio delle persone per risparmiare RAM
